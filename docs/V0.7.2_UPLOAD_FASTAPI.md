# v0.7.2 — New quotation upload / FastAPI analysis only

## Scope
- New quotation upload page now shows one upload box and one Analyze button.
- Selecting/dragging a file begins private Supabase upload immediately.
- `Uploaded` is shown **only after Supabase confirms storage and the database row**.
- Analyze calls the existing authenticated web API, which securely invokes the Python FastAPI extractor.
- The review and quotation pages, costing, rate masters, permissions, company settings, and other flows are unchanged.
- Retry upload works for files that failed to upload; previously saved drawings are retained.

## Required database migration
After replacing the folder, from project root run:

```powershell
supabase db push
```

Migration `0010_drawing_upload_formats.sql` extends only the `drawings` table's supported MIME types and its private Storage bucket's allow-list to cover the drawing formats already shown in the UI. It does not alter RLS policies.

## Local launch (Windows PowerShell)
Keep your existing secrets; place them in `apps/web/.env.local` and `services/extractor/.env`, not in source control.

Terminal 1, project root:

```powershell
npm install
npm run dev:web
```

Terminal 2, project root:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r services/extractor/requirements.txt
npm run dev:extractor
```

Visit `http://localhost:3000/upload` after logging in.

Expected sequence: choose drawing → `Uploading…` → `✓ Uploaded` → click `Analyze Drawing` → FastAPI analysis → reviewed drawing data. Upload speed depends on network and file size; visual AI analysis time depends on drawing complexity and Gemini latency. The FastAPI worker is not needed for the normal path.

If Gemini fails, the existing optional worker queue/retry mechanism is preserved; run `npm run dev:worker` only when needed.
