# Source Truth Reconstruction

This build reconstructs the drawing metadata path without changing unrelated quotation workflows.

## Correct priority
1. Explicit printed drawing/title-block values.
2. AI engineering inference supported by drawing evidence.
3. Deterministic geometry calculation for costing only.
4. Internal fallback only when required for costing; never presented as drawing-extracted data.

## Weight
- Detects Weight / WT / Mass / Net Weight / Unit Weight.
- Locates labels even in CAD PDFs with shifted/corrupted text maps.
- Generates a tight 260-DPI visual crop around the weight row.
- A dedicated Vision pass reads only the printed value and unit; it may not estimate mass.
- Printed weight remains the engineering/display weight.
- Quantity and editable allowance are applied separately to material costing.
- Historical geometry predictions are not reused as authoritative drawing weight.

## Thickness
- Existing real thickness evidence remains supported.
- Historical 100 mm internal fallback values are cleared when no thickness evidence exists.
- Missing real thickness displays blank/dash instead of pretending 100 mm came from the drawing.

## Cache/review safety
- Extraction pipeline version bumped to source-truth-v5-20261007.
- Old extraction caches are ignored.
- Old engineer-review payloads without the current pipeline version are not allowed to override new visible source data.
- Newly saved reviews include the pipeline version.
